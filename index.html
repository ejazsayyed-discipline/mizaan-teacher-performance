Cloud connection

Not connected

This standalone prototype stores changes in this browser on this device. Production cloud sync requires a Firebase project, authentication setup, database rules and deployment configuration. Do not treat local storage as a shared cloud database.

This screen records setup notes only; it does not connect to Firebase or transmit data.

Firebase cloud connection

Not connected

Paste the Web App config from Firebase Project settings. Enable Email/Password Authentication, Firestore Database, and Firebase Storage. Set secure Firestore and Storage rules for authorized staff; never use public read/write rules.

Use an administrator account created in Firebase Authentication (Email/Password). The password is not saved in app settings. Do not enable anonymous database access for confidential teacher records.

Firestore synchronizes teacher, evaluation and settings records. Proof images are compressed before saving. With Firebase connected and Storage enabled, image files are uploaded to Firebase Storage and their references sync with the evaluation records; without cloud connection, images remain on this device.

App access security
